# About This Repository

A centralized repository documenting hands-on learning and implementation across SQL/PL-SQL, C, C++, and HTML/CSS. This repository serves as a collection of practical exercises, coding implementations, and development projects completed while strengthening programming fundamentals, database development skills, problem-solving abilities, and web development knowledge.

## Areas Covered

### SQL & Relational Databases

A collection of practical database exercises and implementations covering query development, data manipulation, schema creation, normalization concepts, and relational database fundamentals. The section focuses on building a strong understanding of database structures, efficient data retrieval, and real-world database operations through hands-on practice.

### PL/SQL Development

Contains procedural database programming implementations designed to extend SQL capabilities through automation and business logic. Exercises focus on developing practical database solutions, improving understanding of Oracle database programming concepts, and applying structured approaches to database-driven applications.

### C Programming

Includes a wide range of coding exercises aimed at strengthening core programming fundamentals and computational thinking. The implementations emphasize logical problem-solving, structured programming techniques, memory concepts, and building confidence with low-level programming constructs.

### C++ Programming

Features practical implementations focused on object-oriented programming and software development fundamentals. The exercises explore class-based design, reusable code structures, and programming practices that help build a strong foundation for modern software development.

### HTML & CSS

Contains frontend development exercises, responsive layouts, user interface implementations, and web design projects. This section focuses on creating structured, accessible, and responsive web pages while applying modern styling techniques and design principles.


## Repository Overview

This repository documents my learning and hands-on practice across SQL, PL/SQL, C, C++, and HTML/CSS. Through practical exercises and implementations, I developed a strong understanding of database concepts, query writing, procedural database programming, and core programming fundamentals.

Alongside database development, I strengthened my problem-solving abilities, logical thinking, and understanding of object-oriented programming concepts using C and C++. I also worked on HTML and CSS projects to build responsive layouts and improve my frontend development skills.

The exercises and implementations in this repository helped me gain practical experience, improve code organization, and reinforce fundamental software development concepts through consistent hands-on learning.
